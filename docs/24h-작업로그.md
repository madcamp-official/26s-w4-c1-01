## 로그

### 블록 D — 카탈로그 GLB 무결성 감사 ✅
- **왜**: 렌더(`place`)는 GLB 원본 크기를, 3D뷰(`Piece`)는 카탈로그 치수로 스케일 → 둘이 다르면 렌더/3D 크기 어긋남.
- **한 일**: `glb_audit.py`로 84개 GLB 전수 로드 → 바운딩박스/메시/재질/텍스처 측정 후 카탈로그 대조.
- **결과**: 84개 **전부 로드 성공·텍스처 보유·카탈로그 치수 일치**(로드실패 0, 텍스처0 0). 즉 렌더↔3D 크기 일관성 OK.
  - "치수 불일치 5건"은 두께 ~1cm 러그 → 상대오차만 큰 오탐(정상). 카테고리 분포 건강(의자16·소파13·테이블13·수납13·침대8·책상8·조명8·러그5).
- **판단**: 카탈로그 수정 불필요. 감사 스크립트만 상시 보관.

### 블록 C — 자동배치 동선 + 배치테스트 ✅ (커밋)
- **한 일**: `circulationScore`(빈 바닥 연결성) 추가 → 랭킹에 동선 0.4 반영. `autolayout.test.js`로 60개 랜덤셋×3후보 겹침0/방밖0 불변식 단언 + 다양성/불가능/LLM폐기/동선 검증.
- **검증**: `npm test` 23개 전부 그린. `npm run build` 통과.

### 블록 A — 렌더 포토리얼 대개조 ✅ (커밋 완료)
- **문제(baseline)**: 바닥 단색 베이지, 창문 백색 덩어리로 과노출, 조명 밋밋, 몰딩/소품 없음 → "실제 사진" 느낌 약함.
- **한 일**:
  - 원목 마루 프로시저 머티리얼(판자 타일 + 나뭇결 + 결 범프) → 바닥 가짜티 제거 (제일 큰 개선).
  - 시간대 조명 프리셋 4종(아침/낮/노을/밤): 노출·환경광·창 색온도·태양광/실내등을 세트로. 밤은 푸른 야경 창 + 따뜻한 실내등.
  - 창문 = 틀 + 십자 창살 → 백색 덩어리 탈출, 창문으로 읽힘.
  - 걸레받이(baseboard) 몰딩, 러그(옵션), 부드러운 그림자용 태양광.
  - `render_server.build_scene`가 preset/rug/window/exposure를 통과하도록 확장.
- **검증**: 고정 5가구 씬을 4개 프리셋 전부 렌더 → PNG 직접 판독. 러그 격리 테스트로 동작 확인. 전부 정상.
