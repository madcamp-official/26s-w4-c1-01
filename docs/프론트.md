# Handoff: 방꾸요정 (방 꾸미기 AI 배치 앱)

## Overview
원룸/방 한 개를 대상으로, 방 치수(치수 선택/도면 가져오기)를 입력하면 실치수 기반 2D 배치 플래너로 가구를 배치하고, AI가 배치 이미지를 합성해주는 앱. 배치 후 부족한 가구는 네이버쇼핑 매칭 상품으로 연결되어 구매까지 이어지고, 완성한 배치를 도장(진행 스탬프)으로 기록한다. 톤은 귀엽고 트렌디한 반말체(인스타 감성), 타겟은 원룸/자취 사용자. **커뮤니티 기능은 이번 범위에서 제외.**

이 프로젝트는 실제 GitHub 레포(`madcamp-official/26s-w4-c1-01`)의 기획서·기능명세서를 기준으로 정합성을 맞췄다 — `github.md` 참고.

## About the Design Files
`방꾸미기 앱 v2.dc.html`(전체 화면 참고 갤러리)과 `방꾸요정 프로토타입.dc.html`(실제 클릭 가능한 인터랙티브 프로토타입)은 **디자인 레퍼런스**이며, 실제 프로덕션 코드로 그대로 옮기는 게 아니다. 실제 구현은 레포의 react-konva 2D 플래너 + FastAPI 백엔드 아키텍처를 따른다. 목표는 이 화면들의 룩앤필과 동작을 그 아키텍처 위에서 재구현하는 것.

## Fidelity
**High-fidelity(hifi)** — 색상, 타이포그래피, 간격, 컴포넌트 형태가 거의 최종안. 이미지/사진 영역은 전부 플레이스홀더(빗금 패턴)이며 실제 촬영/생성 이미지로 교체 필요.

## Screens / Views

### 1. 스플래시 & 소개 캐러셀
카카오톡/배민 스타일 온보딩 캐러셀. "방 사진만 찍으면 가구 배치 뚝딱 ✨" 카피. 스와이프로 페이지 전환, 마지막에 로그인으로.

### 2. 로그인
카카오(`#FEE500`)/네이버(`#03C75A`)/구글(흰 배경) 소셜 로그인 + "나중에 할게요".

### 3. 온보딩 — 취향·예산 (한 페이지)
- **무드** (최대 2개 카드 멀티선택): 포근한 북유럽 / 시크한 인더스트리얼 / 화사한 내추럴 / **모던** / 빈티지 레트로 / 러블리 파스텔 (미니멀 화이트는 모던으로 통합)
- **예산**: 10만원 이하 / 10~30 / 30~50 / 50~100 / 100만원+ (5단계 필 버튼)
- **반려동물 여부** 토글
- 방 크기·기존 가구 재사용 질문은 제거됨 — 넣지 말 것

### 4. 🏠 배치 탭 (홈)
새 방 배치 시작 카드 + 이어서 진행 중 카드 + **나의 방꾸 도장**(취향입력→방입력→배치완성→가구구매 4단계 스탬프) + 통계(완성한 방/저장한 가구). 하단 탭바 🏠배치/🛋️마켓/👤마이.

### 5. 방 치수 선택 / 도면 가져오기
**사진 찍기가 아니라 두 입력 경로**:
- **방 치수 선택**: 평수 버튼(4/5/6.5/8/10평+) 선택 → 화장실·주방 자동 차감 → 예상 방 크기(가로×세로) 자동 계산, "추정 치수" 배지
- **도면 가져오기**: 평면도 이미지 업로드
- 촬영/스캔 가이드 칩: 눈높이로 / 정면·벽 정렬 / 빈 방으로

### 6. 2D 배치 플래너 → AI 합성 결과
레포 아키텍처(react-konva, homography 합성)에 맞춘 2단계 흐름:
- **① 2D 배치 플래너**: 방 직사각형 위에 가구를 실치수 스케일로 드래그 배치, 90도 스냅 회전, AABB 겹침 판정(빨강 하이라이트). 각 가구에 "실치수"/"추정" 라벨. 하단 상태 칩(맞음·문제없음 / 남은 바닥 % / 치수 실측·추정 개수)
- **② 합성 결과**: 배치를 바탕으로 생성된 목업 이미지. 상단에 **"🪄 목업이야 · 실제 조명·재질은 조금 다를 수 있어"** 배지 상시 노출(포토리얼 과잉 약속 금지). **Before/After 토글**로 빈 방 원본 사진과 합성 이미지를 비교 가능(프로토타입에 실제 토글 구현됨). CTA: "다시 배치" / "닮은 상품 찾기"
- **③ 대안**: 가구 리스트형 결과 레이아웃(참고용)
- **④ 합성 실패 시**: 2D 배치도로 폴백(치수 라벨 포함), "이대로 가구 담기"로 흐름 유지
- 로딩 상태: 배치→합성 약 5~7초 스피너 (문구 없이 스피너만, 심플하게)

### 7. 배치/가구 직접 수정 (LLM 채팅) — **범위 미확정**
자연어로 배치 수정 요청("침대랑 자리 바꿔줘") → AI 응답. **부분 수정 방식**: 매번 전체 재생성이 아니라 기존 이미지 위에 요청된 부분만 반영(배치 유지, 조명/색감 등 부분 보정). 레포 명세서엔 없는 기능이라 이번 MVP 포함 여부 확인 필요.

### 8. 🛋️ 마켓 탭
- **카테고리**: 침대 / 책상·의자 / 수납 / 조명 / 러그 — 화면 상단 **상시 노출 세그먼트 탭** (필터가 아니라 1차 탐색 기준이라 바텀시트로 넣지 않음)
- **필터 칩** (분위기/가격대/사이즈/배송, 가로 스크롤, 선택 시 배지형 카운트 표시):
  - **분위기**: 온보딩과 동일한 무드 카드, 최대 2개 바텀시트
  - **가격대**: 5단계 필 버튼 바텀시트 (기존 유지)
  - **사이즈**: 슬라이더 없이 **토글 1개**("우리 방에 맞는 것만") — 방 치수는 이미 5번에서 정해졌으므로 읽기 전용 표시 불필요
  - **배송**: 무료배송만 보기 토글 + 정렬(낮은 가격순/리뷰 많은순/등록일순) — *디자인 미착수, 논의만 됨*
- 필터 적용 시 칩에 배지 반영 + CTA가 "128개 결과 보기"처럼 실시간 결과 수로 갱신
- 상품 카드: 가격 옆에 "실치수"/"추정" 뱃지
- 구매는 **네이버쇼핑으로만** 연결 — 배치에 쓰인 가구(우리 데이터셋, 실치수)와 **정확히 같은 제품이 아닐 수 있는 "닮은 상품"**으로 매칭되는 구조. CTA 문구도 "가구 담기"가 아니라 "닮은 상품 네이버에서 보기"로 이 점을 명시

### 9. 👤 마이 탭
프로필(아바타+닉네임+"수정") + 내 취향 태그(칩, ＋편집으로 재수정) + 배치함(저장된 배치 2열 그리드) + 계정 관리/알림 설정/로그아웃 리스트.

**제외된 화면**: 커뮤니티 피드(인스타형) — 명세서상 중기(Future) 범위라 이번엔 뺌. 개별 가구 AR 미리보기("현재 방에 가구 미리 넣어보기") — homography 기반 일괄 합성 아키텍처와 안 맞고 구현 난이도 높아 제외, 6번 합성 결과가 이 역할을 대신함.

## Interactions & Behavior
- 탭 전환(배치/마켓/마이): 상태 유지 권장
- 필터 바텀시트: slide-up 250~300ms ease-out 권장
- 무드/가격대 선택은 즉시 로컬 상태 반영, API 호출은 "적용하기" 시점
- **로딩 상태**: 배치→합성 약 5~7초, 스피너만(문구 없음)
- **LLM 부분수정(7번)**: 요청마다 전체 재생성이 아니라 기존 배치 유지한 채 요청된 부분만 반영 — 구현은 inpainting/부분 재생성 API 또는 좌표 기반 재배치 후 동일 시드 재렌더링 검토
- 에러 상태 (디자인 미포함, 구현 시 추가 필요): 업로드 실패, AI 생성 실패(→2D 배치도 폴백은 설계됨), 결제/구매 연동 실패

## 무드 ↔ 가구 태그 매핑
실제 가구 데이터는 무드명을 그대로 갖고 있지 않을 수 있으므로, 상품 등록 시 **소재/톤/형태** 3개 속성만 필수 태깅하고 무드는 조합으로 자동 매핑한다.

| 무드 | 소재 | 톤 | 형태 |
|---|---|---|---|
| 포근한 북유럽 | 라이트우드 | 화이트/베이지 | 라운드(둥근 다리) |
| 시크한 인더스트리얼 | 메탈 | 그레이/블랙 | 노출마감(철제 프레임 그대로) |
| 화사한 내추럴 | 라탄/우드밴딩 | 베이지/그레이지 | 라운드 |
| 모던 | 메탈/글라스 | 화이트/그레이/블랙 | 스트레이트/미니멀 |
| 빈티지 레트로 | 다크우드/월넛 | 브라운/어스톤 | 볼륨감(두꺼운 쿠션) |
| 러블리 파스텔 | 패브릭(벨벳/부클) | 파스텔 | 볼륨감 |

## Scope Note (MVP)
- **커뮤니티 피드는 이번 구현 범위에서 제외.** 디자인엔 참고용으로 남아있으나 백엔드/프론트 작업 우선순위에서 뺀다.
- **개별 가구 AR 미리보기도 제외** — 6번 합성 결과로 대체.
- **사이즈 실측/추정(방 크기)은 처리됨** — 백엔드에 방 치수 추정 로직이 이미 있어 별도 논의 불필요.
- **LLM 채팅 부분수정(7번)과 마켓 배송 필터(8번)는 미확정** — 구현 전 확인 필요.

## Design Tokens

### Colors
- Base accent (primary): `#835151`
- Secondary accent (선택/하이라이트, 핑크): `#F08FC0`
- Background: `#FFF3ED` / `#FFF8F3`
- Surface: `#ffffff`
- Muted surface: `#F5F2EE`, `#F1EDE7`
- Text primary: `#2B2118` · secondary: `#8A7A6C` · tertiary: `#9C8B7E`, `#B5A79A` · disabled: `#C7BCAE`
- 카카오: `#FEE500`/`#3A2E00` · 네이버: `#03C75A`
- 목업 배지: `#F08FC0`

### Typography
- `Pretendard Variable`. 헤드라인 800/19~21px, 섹션 타이틀 700~800/13.5~16px, 본문 400/12~14px, 버튼 700~800/12~15px

### Spacing & Shape
- 카드 radius 16~24px, 버튼 14~18px, 칩/배지는 pill(`100px`)
- **모든 pill/배지/짧은 라벨 텍스트에는 `white-space:nowrap` 필수** — 좁은 flex 아이템 안에서 한글이 음절 단위로 줄바꿈되는 문제가 반복적으로 발생했음

### Shadows
- 강조 카드/버튼: `0 8~12px 20~26px rgba(131,81,81,0.16~0.24)`
- 일반 카드: `0 4px 14px rgba(43,33,24,0.06)`

## Assets
- 모든 사진/이미지 영역은 빗금 패턴 플레이스홀더 — 실제 방 사진, 도면, 가구 상품 이미지, AI 생성 배치 이미지로 교체 필요
- 로고: 플레이스홀더("LOGO" 텍스트)
- 네이버 배지: 녹색 원 안 "N" — 실제 연동 시 공식 배지 가이드 확인 필요
