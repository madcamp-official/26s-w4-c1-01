# 방꾸요정 🧚 — 몰입캠프 데모 대본 (3분)

> 목표: 3분 안에 "원룸에 **실측 3D 가구**를 놓고 → **AI가 안 겹치게 자동 배치** → **포토리얼 사진**으로 뽑는다"를 각인.
> 진행: 발표자 1명이 말하며 시연, 1명이 옆에서 백업(네트워크/렌더 대기 커버).

## 0. 사전 준비 (발표 직전 체크리스트)

- [ ] `./run.sh` 실행 → 프런트 빌드 + 백엔드(8000) + camp-3 터널(8600 리라이팅, **8610 렌더**) 올라옴.
- [ ] `curl -s localhost:8610/health` 가 `{"status":"ok"...}` 인지 확인(렌더 서버 살아있음).
- [ ] 브라우저에서 5173 열고 **하드 새로고침**(Ctrl+Shift+R).
- [ ] **미리 한 번 렌더를 돌려 캐시/워밍업**(첫 렌더가 느릴 수 있음). 데모용 방/가구 세트를 미리 담아두면 안전.
- [ ] 화면 공유 시 3D 뷰가 큰 모니터에 잘 보이는지(가구가 작게 안 나오게 시점 조정).
- [ ] **비상 대비**: 렌더 서버가 죽어도 3D 미리보기는 브라우저 WebGL만으로 돌아감 → 최악의 경우 3D까지만 시연하고 "렌더는 GPU 서버에서" 설명으로 대체.

## 1. 타임라인 (초 단위 · 멘트 + 동작)

### ① 문제 제기 — 0:00~0:20 (20초)
> "원룸 이사할 때 제일 어려운 게 가구 배치예요. 침대·책상 사놓고 보니 안 맞거나 문이 막히죠.
> 저희 **방꾸요정**은 원룸에 **실제 치수 3D 가구**를 놓아보고, **AI가 배치까지 해주고**, **실제 사진처럼** 뽑아줍니다."

*(동작: 🧚 방꾸요정 첫 화면)*

### ② 방 만들기 — 0:20~0:40 (20초)
> "먼저 원룸 크기를 넣어요. 사진이 있으면 방 사진으로 치수를 추정할 수도 있고, 직접 입력해도 돼요."

*(동작: 🏠 **방** 탭 → 가로/세로 입력해 방 생성. 예: 3.6m × 5.0m)*

### ③ 가구 담기 — 0:40~1:10 (30초)
> "가구는 **실측 3D 카탈로그**에서 골라요. 아마존 3D 스캔 모델 84종이라 **치수가 실제와 같아요** — 박스가 아니라 진짜 가구죠.
> 네이버 쇼핑 상품을 검색해 담을 수도 있어요."

*(동작: 🛋️ **가구** 탭 → 침대·책상·소파·협탁 등 4~5개 담기. 카테고리별로 있음.)*

### ④ AI 자동 배치 — 1:10~1:50 (40초) ★핵심
> "이제 **자동 배치**. 버튼 하나 누르면 AI가 배치안을 만들어요.
> 중요한 건 — **겹치는 배치는 아예 안 내놔요.** 기하 엔진이 전부 재검증해서 **겹침 0을 보장**하고, 대부분 벽에 붙이고 동선을 살려요.
> 그리고 **후보를 3개** 줘서 취향대로 고를 수 있어요."

*(동작: 🧊 **3D 미리보기** 탭 → ✨ **자동 배치** → 후보 3개 뜨면 하나 선택. 겹침 없이 벽에 붙는 것 강조.)*

### ⑤ 3D로 확인·조정 — 1:50~2:20 (30초)
> "배치는 **진짜 3D**예요. 아키스케치처럼 빙 돌려보고, 마음에 안 들면 **드래그로 옮기고 R키로 돌려요.**
> 전부 브라우저 WebGL이라 설치도 필요 없어요."

*(동작: 마우스 드래그로 시점 회전 → 가구 하나 드래그 이동 → 선택 후 R키로 90° 회전.)*

### ⑥ 포토리얼 렌더 — 2:20~2:55 (35초) ★하이라이트
> "마지막으로 **고품질 렌더**. 지금 이 배치 그대로 GPU 서버에서 **실제 사진처럼** 뽑아요.
> **시간대도 골라요** — 아침·한낮·노을·**밤**. 원목 마루, 창밖 하늘, 조명까지 시간대별로 바뀌어요."

*(동작: 시간대 **밤🌙** 선택 → 📸 **고품질 렌더** → (약 10~30초, 이때 백업 발표자가 멘트 이어감) → 결과 사진.
모달에서 🌅☀️🌇🌙 버튼으로 **원클릭 시간대 전환** 시연 → 저장.)*

*(렌더 대기 중 멘트 예시)*
> "렌더 도는 동안 — 이건 미리 만든 mockup이 아니라 방금 그 3D 배치를 그대로 Blender로 찍은 거예요. 배치를 바꾸면 사진도 바뀌죠."

### ⑦ 마무리 — 2:55~3:00 (5초)
> "**담기 → 자동배치 → 3D 확인 → 사진.** 원룸 꾸미기, 사기 전에 끝냅니다. 감사합니다!"

## 2. 강조 포인트 (심사위원 각인용 3가지)

1. **실측 3D** — 박스가 아니라 치수가 맞는 진짜 3D 가구(ABO 84종). "살 물건이 방에 맞는지"를 실제로 봄.
2. **겹침 0 보장 자동배치** — LLM이 배치안을 내면 **기하 엔진이 전부 재검증**해 겹치는 안은 폐기. 문/창 앞 여유공간도 확보.
3. **포토리얼 + 시간대** — 같은 방을 아침/낮/노을/밤으로. GPU 렌더라 mockup이 아니라 "실제 사진".

## 3. 예상 Q&A

- **Q. 가구가 84개뿐?** → 지금은 큐레이션 실측 3D 84종 + 네이버 검색 상품. 카테고리별 대표 3D로 매칭. 확장은 ABO 3D 데이터셋에서 추가 예정.
- **Q. 렌더 느리지 않나?** → camp-3 40코어 CPU로 방 하나 ~10~30초. 3D 미리보기는 즉시(브라우저).
- **Q. 배치 알고리즘이 진짜 안 겹치나?** → 네. 랜덤 가구셋 다수에 대해 **겹침 0을 테스트로 단언**(60셋×3후보 전수 통과). 못 놓으면 그 안을 폐기.
- **Q. 상용화?** → 3D 모델은 현재 ABO(CC BY-NC, 비상업). 상업 배포 시 라이선스 프리 모델로 교체 필요.
