# 방꾸요정 — 24시간 자율 작업 계획서

작성: 2026-07-25 (다맘 부재 24h) · 작성자: Claude(자율)

## 원칙 (내가 지킬 것)

1. **내가 검증할 수 있는 일만 한다.** 사용자 눈 없이도 옳고 그름을 판별 가능한 작업만 진행.
   - 렌더 품질 → 씬을 렌더해서 나온 PNG를 직접 읽고 사람처럼 평가 → 개선 → 반복
   - 배치 로직 → 기하 검증(겹침 0, 동선 확보)을 프로그램으로 단언
   - 빌드/카탈로그 → `vite build` 통과, 모든 GLB 로드/렌더 성공
2. **데모를 절대 깨지 않는다.** 모든 변경은 가산적·안전하게, 블록마다 커밋/푸시 → 언제든 리뷰·되돌리기 가능.
3. **막히면 멈추고 기록.** 사용자 결정이 필요한 지점(라이선스·키·방향성)은 진행 대신 `docs/24h-작업로그.md`에 질문으로 남긴다.
4. 완료분은 확인 없이 **바로 커밋·푸시**(사용자 상시 지시).

## 24시간 블록 계획

우선순위 = 가치 × 검증가능성. 사용자가 못 박은 최우선 = **"얼마나 실제 같은지"(렌더 포토리얼)**.

### 블록 A (0–5h) — 렌더 포토리얼 대개조 ★최우선
baseline 문제: 바닥 단색·과노출 창·밋밋한 조명·몰딩 없음·소품 없음.
- **A1 원목 마루 바닥** — 프로시저 나뭇결(파장/무늬/노멀) 또는 텍스처. 가짜티 1순위 제거.
- **A2 조명·노출 프리셋** — 아침/한낮/노을/밤 4종(HDRI 세기 + 노출 + 창 발광 색온도). 창문 날아감 방지.
- **A3 벽 디테일** — 은은한 웜톤 + 걸레받이(baseboard) 몰딩.
- **A4 창문** — 창틀 + 창밖 밝은 뷰(하늘/역광), 백색 덩어리 탈출.
- **A5 세트드레싱** — 러그(가구 아래), 필요시 은은한 AO 강화.
- 검증: 매 변경마다 고정 씬 렌더 → PNG 판독. before/after 대조.

### 블록 B (5–8h) — 카메라·프레이밍
- **B1** 사용자가 3D 시점을 안 넘겼을 때 **자동 미남각** 선정(방 전체·클리핑 회피·삼분할).
- **B2** 한 씬 **다각도**(와이드/3-4분면/디테일) 옵션.
- 검증: 렌더 판독.

### 블록 C (8–13h) — 자동배치 견고화
- **C1** 로컬 폴백 개선(벽 밀착 가중치·동선 확보·문/창 여유공간).
- **C2** LLM 프롬프트 few-shot 확장 + 개구부 클리어런스.
- **C3** 배치 배치테스트: 랜덤 가구세트 N개 → **겹침 0 단언 + 도달성(동선) 단언**.
- 검증: `geometry.js`/`autolayout.js` 단언 + 상위 후보 렌더.

### 블록 D (13–17h) — 카탈로그 품질·무결성
- **D1** 85개 GLB 전수 **단독 렌더**로 깨진/이상 스케일 모델 색출 → 컨택시트.
- **D2** 썸네일 누락·치수 오류 보정, 카테고리 커버리지 점검.
- 검증: 전수 렌더 성공 + 컨택시트 판독.

### 블록 E (17–20h) — 빌드 건전성·테스트
- **E1** `vite build` 무경고, 데드코드 정리.
- **E2** `geometry.js`·`autolayout.js` 소형 단위테스트.
- 검증: 빌드·테스트 그린.

### 블록 F (20–24h) — 통합·근거 갤러리·리포트
- **F1** before/after 렌더 + 배치 후보 **증거 갤러리**(사용자가 복귀 즉시 볼 수 있게).
- **F2** 전 작업 상태 리포트 + 열린 질문 정리(`docs/24h-작업로그.md`).
- 검증: 갤러리 아티팩트 + 리포트.
