# 방꾸요정 앱 로고 — 디자인 브리프

> 이 문서 하나만 읽고 작업할 수 있게 썼다. 시안 5개는 이미 벡터로 만들어져 있고
> (`web/public/logo/*.svg`), 이 문서는 **그 시안을 다듬거나 새로 제안할 때의 기준**이다.
> 마지막 갱신: 2026-07-30
>
> **짝 문서**: `design/앱로고_브리프.md` — 포지셔닝·타깃·브랜드 성격을 담은 *기획* 브리프다
> (이미지 생성 모델에 붙여넣는 용도). 이 문서는 그 위의 *기술* 스펙 — 토큰·크기·제약·적용 절차.
> 새 시안을 구상할 땐 그쪽을, 실제 파일로 만들 땐 이쪽을 본다.

---

## 1. 한 줄 요청

원룸 가구배치 앱 **방꾸요정**의 앱 아이콘을, 지금 앱 화면의 분위기(웜 크림 + 브라운, 부드러운 라운드)와
한 몸으로 보이게 만든다. 최종 산출물은 **512×512 벡터 1개**이며, 거기서 파비콘·PWA·안드로이드 런처가 전부 파생된다.

---

## 2. 제품 맥락

| | |
|---|---|
| 무엇 | 한국 **원룸(4~9평)** 가구배치 앱. 방 치수를 넣으면 실치수 3D 가구를 자동 배치하고, 포토리얼 사진으로 미리 보여준다 |
| 누가 | 자취를 시작하는 20대. 대부분 첫 원룸, 가구는 처음 사본다 |
| 차별점 | **실치수**다. "이 침대가 내 방에 들어가나"를 cm 단위로 답한다. 예쁜 무드보드가 아니라 자로 잰 도구 |
| 말투 | 반말·다정함. "방을 예쁘게 채우는 중이야 🧚" / "마음에 드는 걸 고르세요" |
| 이름 뜻 | 방꾸(방 꾸미기) + 요정. **요정이 대신 놓아준다**는 것이 제품의 약속 |

로고가 말해야 할 것은 이 셋 중 하나다 — **방**(공간) / **요정**(대신 해준다) / **실측 배치**(도구다움).
셋을 다 담으려 하면 아이콘이 복잡해져 48px에서 무너진다. **하나만 고르고 나머지는 버린다.**

---

## 3. 브랜드 톤 (실제 화면에서 뽑은 것)

앱은 **밝고 따뜻하고 부드럽다.** 배경이 거의 전부 웜 크림이고, 브라운은 강조에만 아껴 쓴다.
카드는 크게 둥글고(20px), 그림자는 아주 옅다. 차가운 회색은 팔레트에 아예 없다.

로고도 이 안에 있어야 한다. **채도 높은 색, 네온, 딥네이비, 순수 회색은 이 앱의 색이 아니다.**

---

## 4. 디자인 토큰 (`web/src/styles.css` 원본)

```
배경        --bg        #FFF8F3   웜 크림 (앱 대부분의 바탕)
보조 배경   --bg2       #FFF3ED   살짝 더 진한 크림
잉크        --ink       #2B2118   본문 (검정 아님, 웜 다크브라운)
강조        --accent    #835151   브랜드 브라운 ← 로고의 주색
강조 파트너 --accent-2  #D9A793   웜 베이지 (그라디언트/보조 도형)
헤어라인    --line      #ECE3DB
라운드      --r-card 20px · --r-btn 16px · --r-pill 100px
서체        Pretendard (한글), weight 700–800
```

**로고 팔레트는 위에서만 고른다.** 새 색을 도입하지 않는다.
쓸 수 있는 조합은 사실상 둘뿐이다:

- **밝은 안(cream ground)**: `#FFF8F3` 또는 `#FFF3ED` 바탕 + `#835151` 마크 + `#D9A793` 포인트
- **진한 안(brown ground)**: `#835151` 바탕 + `#FFF8F3` 마크 + `#D9A793` 포인트

## 5. 로고가 실제로 쓰이는 자리

| 자리 | 크기 | 파일 | 비고 |
|---|---|---|---|
| 로그인 화면 | 84px | SVG 직접 | 앱에서 로고가 가장 크게 보이는 유일한 곳 |
| PWA 홈 화면 | 192 / 512 | `web/public/icons/icon-{192,512}.png` | |
| PWA 마스커블 | 192 / 512 | `icon-maskable-*.png` | **안드로이드가 원형·스쿼클로 잘라낸다** |

전부 `tools/make-icons.sh <번호>` 한 번으로 생성된다. 원본 SVG만 관리하면 된다.

## 6. 제약 (지키지 않으면 실기기에서 깨진다)

1. **48px에서 판별될 것.** 판정 기준은 384px 시안이 아니라 48px 축소본이다.
   가는 선(스트로크 16 미만 @512), 3개 초과의 도형, 작은 글자는 이 크기에서 사라진다.
2. **마스커블 안전영역**: 중앙 **80%(410×410)** 안에 마크를 넣는다. 바깥 20%는 잘려나간다고 가정.
3. **강조색은 하나.** 바탕 1 + 마크 1 + 포인트 1 = 최대 3색. 그 이상은 앱 톤과 어긋난다.
4. **그라디언트는 아주 얕게만.** 같은 계열 안에서(예: `#9A6260 → #835151`). 대비가 큰 그라디언트는
   축소하면 탁해진다.
5. **글자는 한 글자까지.** '방꾸요정' 네 글자를 넣으면 48px에서 뭉갠다.
6. **정사각 캔버스 512×512, 배경 불투명.** 투명 배경은 마스커블에서 검게 잘린다.
7. 라운드 코너는 **아이콘 파일 안에서 만들지 않는다.** OS가 알아서 깎는다(현재 시안들은 꽉 찬 사각 바탕).

## 7. 현재 시안 5개

전부 `web/public/logo/`에 있다. 파일명 앞 숫자가 곧 선택 번호다.

### 1. 반짝이는 방 — `logo-1-room-spark.svg`
브라운 바탕에 크림색 둥근 사각(=방) 윤곽, 그 안에 반짝임(=요정).
**말하는 것**: 앱 이름 그대로 '방' + '요정'. 진한 바탕이라 홈 화면에서 존재감이 가장 크다.
**약점**: 가구 앱인지는 알 수 없다.

### 2. 침대(위에서 본) — `logo-2-bed.svg`
크림 바탕, 브라운 윤곽의 매트리스 + 베개 둘 + 이불선. 2D 평면도에서 침대를 내려다보는 그 시선.
**말하는 것**: 원룸에서 가장 큰 결정은 침대다. 제품 본질과 가장 가깝다.
**약점**: 베개·이불선이 없으면 그냥 카드로 읽힌다(그래서 넣었다). 침구 앱으로 오해될 여지.

### 3. L자 평면도 — `logo-3-plan.svg`
크림 바탕, 브라운 선으로 그린 L자 방 + 놓인 가구 한 덩이 + 문 열림 호.
**말하는 것**: 실측 배치라는 본질. 실제 원룸이 욕실·현관에 파인 L자라는 것까지.
**약점**: 5안 중 48px에서 가장 불리하다(선이 많다).

### 4. '방' 글자 — `logo-4-bang.svg`
크림 바탕, Pretendard 800 브라운 '방', 우상단 반짝임.
**말하는 것**: 이름. 작을수록 강해지는 유일한 안 — 48px에서도 읽힌다.
**약점**: 무엇을 하는 앱인지 말하지 않는다.

### 5. 요정 지팡이 — `logo-5-wand.svg`
브라운 바탕, 대각선 지팡이 + 흩날리는 반짝임.
**말하는 것**: "요정이 대신 놓아준다"는 약속을 가장 직접.
**약점**: 지팡이 형태가 48px에서 반짝임에 묻힌다.

## 8. 고르는 기준

큰 그림으로 고르지 않는다. 순서대로 본다:

1. **48px 축소본**에서 무엇인지 알아볼 수 있나
2. 홈 화면에 다른 앱들과 섞였을 때 눈에 걸리나 (진한 바탕이 유리)
3. 앱을 열었을 때 로그인 화면·앱 배경과 **같은 세계로 보이나**
4. 위 셋이 비기면, **말하는 것**이 제품 약속에 가까운 쪽

현재 기본값은 **1번**이다 (`web/src/components/Logo.jsx`의 `LOGO_CHOICE`).
이름(방+요정)을 직접 말하면서 48px에서 가장 안전하다고 판단했다.

---

## 9. 적용 방법

```bash
# 1) 번호만 바꾼다
#    web/src/components/Logo.jsx  →  export const LOGO_CHOICE = 3;
# 2) 파생 아이콘 전부 재생성 (파비콘·PWA·마스커블·안드로이드 런처)
tools/make-icons.sh 3
# 3) 웹 재빌드
npm --prefix web run build
```

APK 아이콘까지 바꾸려면 재빌드가 필요하다: `cd android && ./gradlew assembleDebug`

## 10. 하지 말 것

- 집·지붕 모티프 (부동산 앱이 전부 쓴다 — 우리는 '집'이 아니라 '방'이다)
- 창문 모티프 (날씨·부동산 앱과 겹친다)
- 소파 실루엣 (가구 앱 아이콘 중 가장 흔하다)
- 자·줄자 모티프 (실측이 본질이지만 도면 툴처럼 차갑게 읽힌다)
- 얼굴 있는 요정 캐릭터 (48px에서 뭉개지고, 앱의 절제된 톤과 안 맞는다)
- 팔레트 밖의 색, 특히 파랑·초록·순수 회색
